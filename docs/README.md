## 문서 유지 원칙

- 실행 명령, 라우트, 환경변수, 저장 정책은 실제 코드·설정·워크플로와 대조합니다.
- 테스트를 실행하지 않았다면 통과했다고 쓰지 않습니다. CI 결과와 실제 운영 환경 확인도 구분합니다.
- 계획 문서의 체크박스나 과거의 "미완료" 표시는 현재 상태로 간주하지 않습니다.
- 문서가 구현과 충돌하면 현재 코드와 테스트를 먼저 확인한 뒤 문서를 수정합니다.
