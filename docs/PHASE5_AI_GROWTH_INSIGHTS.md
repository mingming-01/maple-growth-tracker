# Phase 5 — AI 성장 분석 고도화

## 목표

AI가 숫자를 계산하거나 결측치를 추정하지 않고, 애플리케이션이 실제 저장된 성장 스냅샷에서 계산한 지표만 해석하도록 한다.

## 분석 기준

- 분석 기준일은 최근 정상 확인된 스냅샷 날짜로 한다.
- 최근 7일과 직전 7일을 비교한다.
- 두 기간을 모두 계산하려면 비교 구간 앞의 기준 스냅샷을 포함해 최대 15개의 일별 스냅샷이 필요하다.
- 같은 날짜의 중복 자료는 정상 확인 기록을 우선한다.
- 하루라도 날짜가 비어 있으면 그 전후 기록을 연결해 성장량을 계산하지 않는다.
- 레벨이 오른 날짜는 경험치가 초기화되므로 해당 날짜의 경험치 증가량 비교에서 제외한다.
- 레벨이 같고 경험치가 감소한 비정상 구간도 비교에서 제외한다.
- 비교 표본이 충분하지 않으면 변화율이나 요일별 비중을 반환하지 않는다.

## 계산 항목

| 지표 | 계산 방식 |
|---|---|
| 최근 7일 평균 | 연속된 날짜이며 레벨이 유지된 유효 성장 구간의 평균 |
| 직전 7일 평균 | 동일한 방식으로 계산 |
| 기간 변화율 | 두 기간의 관측 평균이 충분할 때만 계산 |
| 주중·주말 평균 | 각 구간의 실제 관측 성장량을 별도 집계 |
| 주말 성장 비중 | 주말 관측 성장량 / 전체 관측 성장량 |
| 데이터 충실도 | 분석 구간의 정상 스냅샷 수 / 기대 스냅샷 수 |
| 분석 기준일 | 최근 정상 확인된 스냅샷 날짜 |

## AI의 역할

Gemini 또는 OpenRouter에는 위에서 계산한 결과와 기존 성장 지표를 전달한다. AI는 수치를 다시 계산하지 않으며, 입력에 존재하는 변화율과 요일별 비중만 문장에 사용할 수 있다. 충분한 표본이 없는 항목은 판단 보류로 설명해야 한다.

## 표시 항목

AI 리포트 상단에 분석 기준일, 분석 대상 기간, 데이터 충실도, 확인 스냅샷 수, 최근·직전 7일의 유효 변화 구간 수, 기간 변화율, 주말 성장 비중을 표시한다.

## 검증

- 결측 날짜를 건너뛰어 차이를 계산하지 않는지 확인
- 레벨업 구간을 경험치 증가량에 포함하지 않는지 확인
- 정상 스냅샷 15개일 때 최근 7일과 직전 7일을 비교하는지 확인
- 기준 기간 데이터가 부족할 때 변화율을 null로 반환하는지 확인
- AI API 응답의 근거 정보가 캐시와 새로고침 후에도 유지되는지 E2E로 확인
