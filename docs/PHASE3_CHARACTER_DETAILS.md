# Phase 3 캐릭터 상세 정보

## 목적

성장 기록과 별도로 캐릭터의 현재 상세 구성을 확인한다. 기본 캐릭터 검색은 기존 응답을 유지하고, 상세 데이터는 사용자가 탭을 선택했을 때만 조회한다.

## 화면 구성

- 스탯: 주요 스탯, 현재 적용 상태 전투력, 하이퍼 스탯 프리셋, 어빌리티 프리셋
- 장비: 장비 프리셋, 아케인·어센틱 심볼, 세트 효과
- 링크 스킬: 링크 스킬 프리셋
- 유니온: 유니온 기본 정보, 공격대 프리셋, 아티팩트 프리셋

프리셋은 각 데이터 영역에서 독립적으로 선택한다. 장비 1번과 하이퍼 스탯 1번 등이 같은 조합이라는 가정은 하지 않는다.

## Nexon API 연동

| 화면 | Nexon Open API 경로 |
|---|---|
| 주요 스탯 | `character/stat` |
| 하이퍼 스탯 | `character/hyper-stat` |
| 어빌리티 | `character/ability` |
| 장비 | `character/item-equipment` |
| 심볼 | `character/symbol-equipment` |
| 세트 효과 | `character/set-effect` |
| 링크 스킬 | `character/link-skill` |
| 유니온 기본 | `user/union` |
| 유니온 공격대 | `user/union-raider` |
| 유니온 아티팩트 | `user/union-artifact` |

각 엔드포인트는 OCID로 요청한다. 상세 정보 라우트는 `GET /api/character-details?ocid=...&section=stats|equipment|link|union`이다.

## 지연 조회와 실패 처리

- 기본 캐릭터 검색은 상세 API를 호출하지 않는다.
- 상세 탭을 선택한 시점에 해당 영역의 API만 호출한다.
- 동일 OCID와 영역의 상세 응답은 서버 메모리에 5분 캐시한다.
- 선택한 영역의 API 중 일부만 실패하면 성공한 데이터는 표시하고 해당 카드만 조회 불가로 표시한다.
- 상세 API가 실패해도 캐릭터 기본 정보, 성장 그래프, 기간별 통계에는 영향을 주지 않는다.
- API의 빈 응답은 데이터 없음으로, HTTP 오류나 연결 오류는 조회 불가로 구분한다.

## 프리셋 및 전투력 표시 원칙

- Nexon API 응답의 활성 프리셋 번호를 기본 선택으로 사용한다.
- 실제 응답에 존재하는 프리셋만 선택지로 표시한다. API가 제공하지 않는 프리셋을 임의로 만들지 않는다.
- 주요 스탯 API의 `final_stat`에서 `전투력` 항목을 찾으면 현재 적용 상태의 전투력을 별도로 강조한다.
- 프리셋별 전투력 또는 환산 점수가 API 응답에 별도로 포함되지 않는 경우, 비활성 프리셋의 전투력·환산 점수를 추정하거나 최고 프리셋이라고 단정하지 않는다.
- 프리셋 구성 데이터만으로 실제 전투력이나 환산 주스탯을 정확히 재현하려면 게임 계산식, 버프 조건, 보스 설정 등 추가 조건이 필요하다. 별도 계산기가 구축되기 전까지 API가 반환한 현재 전투력과 프리셋 구성 비교를 구분한다.

## 테스트 범위

- 유니온 공격대·배치 프리셋을 같은 선택 항목으로 묶는 처리
- 현재 전투력 추출
- 일부 Nexon API 실패 시 부분 성공 상태 반환
