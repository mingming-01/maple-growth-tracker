# 조회 갱신 동작과 한계

## 사용 흐름

1. 게임에서 캐릭터 상태가 반영되도록 필요한 동작을 한다. 일부 외부 메이플 사이트는 캐시샵 입장 또는 캐릭터 선택 화면에서 재접속한 뒤 약 1분을 기다렸다가 갱신하도록 안내한다.
2. Maple Growth Tracker에서 브라우저를 새로고침하거나 **최신 정보 다시 조회**를 누른다.
3. 앱은 자체 메모리 캐시와 브라우저 HTTP 캐시를 우회해 NEXON Open API에 현재 공개된 캐릭터 정보와 최근 7일 랭킹 기록을 다시 요청한다.
4. API 응답이 일시적으로 실패하면 저장된 마지막 정상 응답이 있을 경우 이를 반환하고, 화면에 오래된 데이터임을 표시한다.

## 브라우저 새로고침

- 조회 결과는 같은 탭의 `sessionStorage`에서 먼저 복원해 화면을 빠르게 표시한다.
- 복원된 결과가 있으면 최신 공개 데이터를 다시 조회한다.
- 반복 새로고침에 따른 외부 API 호출 급증을 줄이기 위해 자동 갱신은 성공한 자동 갱신 이후 60초 안에는 다시 실행하지 않는다.
- 자동 갱신이 생략되더라도 사용자가 **최신 정보 다시 조회** 버튼을 누르면 별도로 갱신을 요청할 수 있다.

## 갱신의 한계

- 웹앱은 게임 클라이언트에 연결해 캐시샵 진입, 캐릭터 선택, 로그아웃 같은 동작을 대신 실행할 수 없다. 브라우저 갱신은 NEXON Open API에 새로운 조회를 요청하는 동작이며, 넥슨 서버에 저장된 캐릭터 데이터 자체를 강제로 갱신하지는 않는다.
- 인게임 동작 후에도 공개 API에 정보가 반영되기까지 지연이 생길 수 있다. 화면의 조회 시각은 **웹앱이 조회한 시각**이지, 게임 서버가 해당 값을 실제로 갱신한 시각이라는 보장은 없다.
- 랭킹은 실시간 전투 상태 스트림이 아니다. 넥슨은 당일 랭킹 조회 가능 시간을 2026년 6월 22일부터 오전 9시 30분으로 조정했다고 공지했다. 집계가 늦어지면 더 늦게 제공될 수 있다.
- 이 단계의 SQLite 스냅샷은 마지막 정상 응답을 복원하기 위한 임시 기반이다. Render의 영구 데이터 보존을 보장하지 않으므로, 날짜별 장기 기록을 만들기 전에 영구 저장소를 별도로 선정해야 한다.
